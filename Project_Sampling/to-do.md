## 2. Pemrograman ESP (C++ / Arduino IDE)

### A. Update Format Pengiriman JSON
Pastikan payload JSON yang dikirimkan oleh ESP (saat melakukan POST data ke `http://<IP-SERVER>:3000/api/data`) memiliki *key* yang lengkap seperti di bawah ini:

```json
{
  "device": "Chamber 1", 
  "suhu": 32.5,
  "kelembaban": 65.0,
  "tekanan": 1012,
  "gas_metana": 450,
  "syringe_present": 1
}
```
**Catatan Penting:**
- `"device"`: Isi dengan nama permanen alat (misal "Chamber 1" atau "Chamber 2"). Nama ini yang akan dideteksi oleh fitur registrasi otomatis di website.
- `"syringe_present"`: Diisi secara dinamis (live) dengan angka `1` (jika limit switch pendeteksi syringe tertekan/ada suntikan), dan `0` (jika dilepas/kosong).

### B. Integrasi 3 Limit Switch (Fisik)
- [ ] **Limit Switch 1 (Pendeteksi Syringe):** Digunakan murni untuk membaca status `1` atau `0` lalu mengirimkannya lewat variabel `"syringe_present"` di atas.
- [ ] **Limit Switch 2 (Batas Atas / Mentok Atas):** Pastikan di dalam programmu (saat motor bergerak ke `"UP"`), tambahkan kondisi **berhenti darurat (STOP)** jika Switch ini tertekan agar alat tidak rusak.
- [ ] **Limit Switch 3 (Batas Bawah / Mentok Bawah):** Pastikan di dalam programmu (saat motor bergerak ke `"DOWN"`), tambahkan kondisi **berhenti darurat (STOP)** jika Switch ini tertekan.

### C. Pembacaan Perintah dari Server
ESP harus bisa membedakan eksekusi dari dua nama perintah:
- [ ] **Perintah Kipas:**
  - Jika `command_name == "kipas"` dan `command_value == "ON"` $\rightarrow$ Aktifkan pin Relay Kipas.
  - Jika `command_name == "kipas"` dan `command_value == "OFF"` $\rightarrow$ Matikan pin Relay Kipas.
- [ ] **Perintah Syringe:**
  - Jika `command_name == "syringe"` dan `command_value == "UP"` $\rightarrow$ Putar Stepper/Motor ke atas (menarik suntikan).
  - Jika `command_name == "syringe"` dan `command_value == "DOWN"` $\rightarrow$ Putar Stepper/Motor ke bawah (mendorong suntikan).
